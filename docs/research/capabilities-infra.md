# Research: capabilities-infra

## Summary

Recommended defaults for Gora. Each one sits behind a small interface, has a fake implementation for tests, and has a fallback provider. Anything marked verified was checked live on 2026-09-28: npm registry, curl probes of MCP servers and public APIs, a local geo-tz test on Node 26.8.1, and the local Claude API skill docs.

(1) Speech-to-text. Default is Groq whisper-large-v3-turbo on its OpenAI-compatible endpoint, POST https://api.groq.com/openai/v1/audio/transcriptions. It costs $0.04 per audio hour with a 10 s minimum per request, so about $0.00011 per voice note, and it accepts ogg directly. The free tier is org-wide and small (20 RPM, 2,000 RPD, 7,200 audio-sec/hour), so production needs a paid Groq tier. Fallback 1 is OpenAI gpt-transcribe at $0.0045/min (or gpt-4o-mini-transcribe at $0.003/min): same multipart shape, only baseURL and model change. Fallback 2 is Deepgram nova-3 at $0.0043/min, billed per second. It takes raw bytes with Ogg/Opus auto-detected, and its auth header is `Token`, not Bearer. ElevenLabs scribe_v2 ($0.22/hr) and AssemblyAI (upload, then submit, then poll; $0.15–0.21/hr) work but are more expensive or more complex. Critical gotcha: Telegram voice files have a .oga extension, and Whisper-compatible endpoints reject .oga. Upload the unchanged bytes with the filename voice.ogg. Never pass Telegram file URLs to a provider's `url` parameter, because those URLs contain the bot token.

(2) Text-to-speech. Default is OpenAI gpt-4o-mini-tts with response_format:"opus", which returns Ogg/Opus that can go straight to sendVoice with no ffmpeg (about $0.015/min; voices marin or cedar recommended). Fallback is ElevenLabs eleven_flash_v2_5 or eleven_v3 with output_format=opus_48000_64 ($0.05–0.10 per 1K chars), which is also Ogg/Opus. sendVoice accepts OGG/OPUS, MP3 or M4A up to 50 MB, but only Ogg/Opus shows up as a proper voice bubble with speed controls. OpenAI requires telling users the voice is AI-generated.

(3) Cloud computer:
- **v1: no autonomous browser.** Use research only: Claude server tools web_search_20260209 ($10 per 1K searches) and web_fetch_20260209, plus no-auth MCP servers such as Kiwi flights (`search-flight`). Output is summaries, deep links and drafts.
- **v2: a per-user Browserbase session with a per-user Context** (persistent cookies and logins).
  - Driven by Claude's `computer_toolset_20260801` (GA, no beta header, works on claude-opus-5) through our own thin adapter: Playwright `connectOverCDP`, with screenshot, click, type, key and scroll mapped to page.mouse and page.keyboard.
  - Browserbase's live view (`sessions.debug` → `debuggerFullscreenUrl`) is embedded in the Telegram Mini App so the user types logins, 2FA and card details themselves.
  - Browserbase pricing: Developer plan $20/mo with 100 hrs, then $0.12/hr.
  - Fallback is Steel ($0.10/hr, $30 one-time free credit, open-source and self-hostable). Its Credentials API autofills per-origin logins so the agent never sees passwords.
  - Sentinel is a separate policy service in our process that decides allow, deny or ask, modeled on Meta's design:
    - Rules first: domain allowlists and action classes such as submit, pay and send.
    - Taint tracking: once a task has read private data, any new outbound request or form submit asks the user.
    - Approvals appear as a separate Telegram message with inline buttons and in the Mini App, never inside the chat reply. Each approval is scoped (once, task, time-bound, always).
    - Credentials are placeholders swapped in at the network boundary.
    - Every decision goes to a SQLite audit log.
  - Anthropic Managed Agents is a possible later backend for background tasks. It already has `always_ask`, vault credentials swapped in at egress, restricted networking and cron deployments, at $0.08 per session-hour plus tokens. It is still beta and has no GUI browser.

(4) Integrations. v1 default is Composio: free for 100K tool calls a month with unlimited connected accounts; Scale is $29/mo plus $0.0003 per call. It provides managed OAuth apps (including Google), Connect Links that can be sent in chat, and triggers for proactive features.
- Run Composio tools client-side with @composio/anthropic in our own loop so every call passes through Sentinel.
- Anthropic's MCP connector runs tool calls server-side, so they skip our approval gate. Use it only for read-only or no-auth servers, and with tool allowlists.
- Fallback for many apps is direct remote MCP with our own OAuth client via @modelcontextprotocol/sdk. Verified dynamic client registration (DCR): Notion, Linear, Todoist, Canva, Airtable, Dropbox, Monday, ClickUp, Miro, Figma, Attio, Granola, Stripe, PayPal. CIMD also works for Notion, Linear, Todoist, Canva, Airtable and Granola.
- Slack, Asana, GitHub, HubSpot, Box and Google do not support DCR and need an OAuth app registered in advance.
- Google Workspace's official MCP servers (gmailmcp/calendarmcp/drivemcp.googleapis.com/mcp/v1) are in Developer Preview, need your own GCP OAuth client, and the Gmail server has no send tool (drafts only).
- Pipedream Connect ($99/mo annual for 100 external users), Nango ($0.29 per connection) and Arcade ($0.01 per call plus $0.10 per auth event) cost too much for a consumer bot.

(5) Timezone. First choice: the Mini App reports `Intl.DateTimeFormat().resolvedOptions().timeZone`. For a shared location, use geo-tz@8.1.9 with its default entry. Do not use geo-tz/now: in the local test it returned Asia/Karachi for Almaty and Europe/Athens for Kyiv. For a typed city, the Open-Meteo geocoding response includes `timezone`. Lightweight fallback is @photostructure/tz-lookup@11.7.0 (96 KB, about 5–10% wrong in populated areas). tz-lookup@6.1.25 has been abandoned since 2019.

(6) Public data. Open-Meteo for forecast, air quality and geocoding (free for non-commercial use only; the Standard plan is about $29/mo for 1M calls). MET Norway is a fallback. Also: Nager.Date holidays, Frankfurter (ECB rates only, no KZT or RUB), open.er-api.com (166 currencies including KZT and RUB), sunrise-sunset.org, and Nominatim or Photon for reverse geocoding. For flights: Kiwi MCP for search, adsb.lol and OpenSky for live positions, and AeroDataBox ($8/mo on RapidAPI) for status by flight number.

- **[verified] STT gotcha: Telegram .oga extension**: Telegram voice notes download as voice/file_N.oga (Ogg/Opus). Groq and other Whisper-compatible endpoints reject the .oga filename with 400 unsupported_audio_format, but the same bytes named voice.ogg work. Fix: upload with filename 'voice.ogg' and content type audio/ogg, no transcoding. Download via getFile, then https://api.telegram.org/file/bot<token>/<file_path>. The cloud Bot API download limit is 20 MB. Never send the file URL to a provider's `url` param, since it contains the bot token. _(source: https://github.com/chigwell/telegram-mcp/issues/219 ; core.telegram.org/bots/api ("The maximum file size to download is 20 MB"))_

- **[verified] Meta Muse Sentinel design (to mirror)**: Sentinel is the only permission authority. The agent proposes actions and Sentinel returns allow, deny or ask. It checks every connector action and every network egress at L4 (host, resolved IP, port, protocol) and L7 (method, path, body). Kernel-level taint tracking (eBPF): a process becomes tainted after reading user data, and a tainted request loses auto-allow. Approvals appear in the client UI, not in the agent chat, and are scoped as one-time, session, task, time-bounded or perpetual. Credentials are inserted just in time: surrogate tokens are replaced by real ones at the network boundary. Duties are split three ways: Privsep decides where credential-capable code runs, Authd decides which credentials a caller receives, and Sentinel decides whether an action is allowed. _(source: https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse ; quasa.io / eesel.ai coverage)_

## Implications for Gora

- Put each provider behind a small interface and inject `fetch` into every adapter so tests can pass a fake fetch without keys. Interfaces: SpeechToText.transcribe(bytes, {filename:'voice.ogg', mime:'audio/ogg', lang?}) → {text, lang?}; TextToSpeech.synthesize(text, {voice, lang}) → {bytes, mime:'audio/ogg'}; BrowserProvider.createSession({userId, profileId}) → {id, cdpUrl, liveViewUrl}; IntegrationProvider.{listTools, connectLink, execute}; Sentinel.evaluate(action, ctx) → allow | deny | ask; TimezoneResolver; WeatherProvider; FlightProvider. Ship Fake* implementations and replayable HTTP fixtures, including a real .ogg voice fixture.
- STT: write one OpenAICompatibleSTT class (baseURL, model, apiKey). The default is Groq whisper-large-v3-turbo; OpenAI gpt-transcribe or gpt-4o-mini-transcribe uses the same class with a different config. Add a DeepgramSTT class (raw bytes, `Token` auth) as the non-OpenAI fallback. Always download the file via getFile (≤20 MB), rename .oga to .ogg in the multipart filename, and never forward the Telegram file URL. Use no SDKs, plain fetch plus FormData/Blob built into Node 26.
- TTS is optional and off by default. Use OpenAI gpt-4o-mini-tts with response_format 'opus' and send the bytes directly with grammY's sendVoice(new InputFile(buf, 'reply.ogg')); no ffmpeg dependency. ElevenLabs opus_48000_64 is the fallback. Say once in onboarding that voice replies are AI-generated.
